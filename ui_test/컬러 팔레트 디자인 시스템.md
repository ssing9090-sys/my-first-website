## 컬러 사용 가이드

### 사용 비율
| 그룹 | 비율 | 역할 |
|---|---|---|
| 배경 (`--color-bg-*`) | 약 70% | 넓은 여백으로 콘텐츠 가독성 확보 |
| 텍스트 (`--color-text-*`) | 약 18% | 회색 명도 단계로 정보 위계 표현 |
| 테두리 (`--color-border*`) | 약 7% | 카드·리스트·섹션 구분 |
| 프라이머리 그린 | 약 4% | 클릭 가능한 요소에만 사용 |
| 액센트 레드 | 약 1% | 꼭 봐야 하는 신호에만 사용 |

### Primary — `#03C75A` 계열
- **사용**: 주요 CTA 버튼(연락하기, 프로젝트 보기), 활성 탭·내비게이션, 진행 표시, 포커스 링
- **`--color-primary-dark`**: 버튼 hover/pressed 상태, 흰 배경 위 작은 그린 텍스트
- **`--color-primary-light`**: 선택된 카드 배경, 기술 스택 태그 배경, 강조 박스
- **주의**: 한 화면에 그린 버튼은 1~2개로 제한. 흰 바탕 위 그린 텍스트는 대비가 낮으므로(약 2.3:1) 본문 크기 텍스트에는 `--color-primary-dark` 사용

### Secondary — `#333333`
- **사용**: 본문 텍스트, 보조 버튼(아웃라인/텍스트 버튼), 푸터 배경, 아이콘 기본색

### Accent — `#FF4E59`
- **사용**: "NEW" 배지, 알림 점, 폼 에러 메시지, 필수 입력 표시(*)
- **주의**: 장식 목적으로 사용 금지. 버튼 배경으로 쓰지 않음

### Background
- **`--color-bg-primary` (#FFFFFF)**: 페이지 기본 배경, 카드·모달 배경
- **`--color-bg-secondary` (#F8F8F8)**: 섹션 교차 배경(Hero → About → Projects 구분), 사이드바
- **`--color-bg-tertiary` (#F2F2F2)**: 리스트 항목 hover, 비활성 입력창

### Text
- **`--color-text-heading` (#222222)**: h1~h3 제목
- **`--color-text-primary` (#333333)**: 본문 단락
- **`--color-text-secondary` (#666666)**: 프로젝트 설명, 부제, 메타 정보
- **`--color-text-muted` (#999999)**: 날짜, 캡션, placeholder (중요 정보에는 사용 금지 — 대비 2.8:1)

### Border
- **`--color-border` (#E5E5E5)**: 카드 테두리, 구분선(`<hr>`), 리스트 구분
- **`--color-border-strong` (#DDDDDD)**: 입력창·아웃라인 버튼 테두리

### Interactive
- **버튼**: 기본 `--color-button-primary` + 흰 텍스트 → hover 시 `--color-button-hover`
- **링크**: `--color-link`, hover 시 `--color-link-hover` + 밑줄
- **비활성**: 배경 `--color-bg-tertiary`, 텍스트 `--color-text-muted`

### 사용 예시
```css
.button--primary {
  background-color: var(--color-button-primary);
  color: #FFFFFF;
  border: none;
}

.button--primary:hover {
  background-color: var(--color-button-hover);
}

.card {
  background-color: var(--color-bg-primary);
  border: 1px solid var(--color-border);
}

.card__description {
  color: var(--color-text-secondary);
}
```

## 반응형 고려사항

### 다크모드
시스템 설정을 따르되, 사용자가 직접 전환할 수 있도록 `data-theme` 속성도 지원합니다.

```css
@media (prefers-color-scheme: dark) {
  :root:not([data-theme='light']) {
    --color-primary: #1FD171;
    --color-primary-light: #0F3A24;
    --color-primary-dark: #03C75A;

    --color-secondary: #E5E5E5;
    --color-accent: #FF6B74;

    --color-bg-primary: #1B1C1E;
    --color-bg-secondary: #222326;
    --color-bg-tertiary: #2C2D31;

    --color-text-heading: #F2F2F2;
    --color-text-primary: #E5E5E5;
    --color-text-secondary: #B3B3B3;
    --color-text-muted: #8A8F94;

    --color-border: #323232;
    --color-border-strong: #444444;

    --color-button-primary: #03C75A;
    --color-button-hover: #1FD171;
    --color-link: #1FD171;
    --color-link-hover: #5BE59A;
  }
}

:root[data-theme='dark'] {
  /* 위 다크모드 변수와 동일한 값 적용 */
}
```

**다크모드 원칙**
- 순수 검정(#000) 대신 `#1B1C1E`를 사용해 눈의 피로를 줄임
- 어두운 배경에서는 그린을 한 단계 밝게(`#1FD171`) 조정해 대비 확보
- 그림자 대신 배경 명도 차이(`bg-primary` → `bg-secondary` → `bg-tertiary`)로 깊이 표현
- 이미지·스크린샷은 `opacity: 0.9` 정도로 살짝 낮춰 눈부심 완화

### 화면 크기별 적용
| 화면 | 기준 | 색상 적용 방법 |
|---|---|---|
| 모바일 | xs (0px~) | 섹션 배경 교차를 줄이고 `bg-primary` 위주로 단순화. 하단 고정 CTA 버튼에 primary 사용 |
| 태블릿 | md (900px~) | 섹션별 `bg-primary` / `bg-secondary` 교차 배경으로 영역 구분 |
| 데스크톱 | lg (1200px~) | 카드 hover 시 `border` → `primary` 색 전환 등 마우스 인터랙션 색상 추가 |

**모바일 주의사항**
- 터치 기기는 hover가 없으므로 `:active` 상태에도 `--color-button-hover` 적용
- 야외 밝은 환경을 고려해 모바일 본문 텍스트는 `--color-text-muted`(#999) 사용을 피함

### 접근성 (WCAG 2.1 대비 기준)
| 조합 | 대비 | 판정 |
|---|---|---|
| `#333333` on `#FFFFFF` | 12.6:1 | AAA ✅ |
| `#666666` on `#FFFFFF` | 5.7:1 | AA ✅ |
| `#999999` on `#FFFFFF` | 2.8:1 | 캡션 전용 ⚠️ |
| `#FFFFFF` on `#03C75A` | 2.3:1 | AA 미달 (장식·아이콘 위주) ⚠️ |
| `#FFFFFF` on `#009F47` | 3.5:1 | 큰 텍스트 AA ✅ |

> 흰 텍스트가 올라가는 버튼은 `#03C75A` 원색이 대비 기준에 못 미치므로, 접근성이 중요하면 버튼 배경을 `--color-primary-dark`(#009F47)로 쓰고 텍스트는 18px 이상 + `font-weight: 700`으로 쓰는 것을 권장합니다.
